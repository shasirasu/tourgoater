# Tourgoater

## Project Idea

Tourgoater is a trip-planning application that helps travellers discover destinations, compare accommodation options, choose a transport type, and plan a trip within a budget.

## Problem

Travellers often check destinations, hotels, transport, and expenses in different places. This makes it difficult to understand the total estimated cost of a trip.

## Target User

A budget-conscious traveller who wants to organize a simple trip and check whether it fits their available budget.

## Main User Workflow

1. The user creates an account or logs in.
2. The user browses destinations by category, such as Beach, Mountain, or City.
3. The user selects a destination.
4. The app displays hotels and resorts available in that destination.
5. The user selects an accommodation and enters travel dates.
6. The user chooses a transport type, such as Flight, Train, or Bus.
7. The user enters their total trip budget.
8. The app calculates the estimated travel and accommodation costs.
9. The user saves the trip plan to their account.

## Week 9 MVP Features

- User registration and login
- Browse destinations by category
- View accommodation information and sample availability
- Create and save a trip plan
- Calculate estimated trip expenses
- View, edit, and delete saved trips

## Planned Data Entities

- `users`
- `destinations`
- `accommodations`
- `trips`

## Future Features (Not Part of the MVP)

- Real hotel or resort booking
- Live flight and train information
- Real payment processing
- A real digital wallet
- Live prices from external travel services

## Week 9 Success Checkpoint

The first version is successful when a logged-in user can browse sample destinations, create a trip with accommodation, transport, dates, and budget details, and save that trip.
